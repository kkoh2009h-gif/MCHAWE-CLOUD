# MCHAWE CLOUD

## هدف النسخة الحالية: تطبيق PS4 بصيغة PKG

المطلوب النهائي هو تطبيق PS4 أصلي قابل للتثبيت عبر ملف `.pkg` على جهاز PS4 مع GoldHEN. الموقع وPWA ليسا المنتج النهائي.

## وضع البناء الأصلي الحالي
- `ps4/src/main.c` و`ps4/Makefile` ينتجان ELF/`eboot.bin` عبر OpenOrbis.
- Workflow `.github/workflows/build-ps4.yml` يبني مخرجات native scaffold ويرفعها مع `build-info.txt` و`SHA256SUMS`.
- **هذا الـworkflow لا ينشئ PKG حتى الآن**؛ لا يُعد التطبيق جاهزاً للتثبيت.
- هدف التطوير التالي هو توفير GP4/metadata/package step موثوقة ثم بناء PKG والتحقق من Artifact قبل تسليم المستخدم.


مشروع MCHAWE CLOUD هدفه تقديم تجربة Xbox Cloud Gaming على PS4 بشكل يحمل اسم وهوية MCHAWE، بالاعتماد على محرك PSBox Cloud Gaming الأصلي بدلاً من واجهة ويب تجريبية.

## الوضع الحالي (بصراحة)
- الواجهة الحالية في `index.html` مجرد prototype / mockup وليست تطبيق بث.
- لا يوجد تسجيل Microsoft أو بث ألعاب أو PS4 PKG جاهز في هذا المستودع حالياً.
- ملف `ps4/` السابق يحتوي scaffold بسيط فقط، وليس محرك بث.
- الخطوة التقنية المطلوبة هي دمج/إعادة بناء المشروع على أساس upstream PSBox مع الحفاظ على متطلبات ترخيص GPL-3.0-or-later، وإضافة هوية MCHAWE وإعدادات/واجهة مناسبة.

## محرك المشروع الأساسي
- **PSBox Cloud Gaming**: https://github.com/RafaelNGP/psbox-cloud-gaming
- **الإصدارات الرسمية**: https://github.com/RafaelNGP/psbox-cloud-gaming/releases/latest
- **ترخيص upstream**: GPL-3.0-or-later (يجب الحفاظ على إشعارات الترخيص وحقوق المؤلف وشروط إعادة التوزيع عند الاشتقاق).

PSBox يوفّر محركاً أصلياً يتضمن كتالوج Xbox Cloud Gaming، تسجيل الدخول عبر Microsoft، streaming، ودعم PS4 مع GoldHEN بحسب توثيق upstream. يتطلب حساب Microsoft وخطة اشتراك/خدمة مؤهلة؛ المشروع لا يتجاوز متطلبات الاشتراك أو القيود الإقليمية.

## خارطة طريق الدمج
1. مراجعة بنية upstream والترخيص والاعتماديات.
2. إنشاء fork أو نسخة مشتقة مع الحفاظ على ملفات GPL والـ notices.
3. تخصيص branding وواجهة MCHAWE، دون تعطيل تسجيل الدخول أو البث أو التحديثات الأساسية.
4. بناء PS4 PKG باستخدام OpenOrbis toolchain.
5. اختبار PKG فعلياً على PS4 وGoldHEN قبل إعلان جاهزيته.

## بناء نسخة PSBox الأصلية عبر GitHub Actions

أضيف workflow يدوي باسم `.github/workflows/build-psbox-baseline.yml`:
- يجلب PSBox عند commit محدد مع submodules.
- يثبت أدوات البناء في Ubuntu.
- ينفذ إعداد CMake وبناء Release ومحاولة إنشاء PKG.
- يرفع ملف PKG كـ Artifact لمدة 7 أيام إذا نجحت جميع الخطوات.

**تنبيه:** لم يتم تشغيل الـ workflow من هنا؛ واجهة GitHub المتاحة لا تسمح بتشغيل workflow dispatch. لذلك البناء غير متحقق بعد، وقد يحتاج workflow إلى إصلاحات بحسب نتيجة أول تشغيل.

## الواجهة التجريبية الحالية
فتح `index.html` يعرض نموذج واجهة فقط؛ لا يُعد تشغيل الألعاب أو بثها.

### تحسينات واجهة تم تنفيذها
- زر تثبيت PWA صار مربوطاً بـ `beforeinstallprompt` ويظهر فقط عند دعم المتصفح لعملية التثبيت.
- تسجيل Service Worker تلقائي عند تحميل الصفحة.
- كاش Offline جديد `mchawe-cloud-v2` مع `skipWaiting()` و`clients.claim()` وتنظيف كاش النسخ السابقة.
- التنقل بين بطاقات الألعاب بالأسهم على لوحة المفاتيح/يد التحكم (يمين/يسار، أعلى/أسفل) عند تركيز بطاقة.
- عند فتح تفاصيل اللعبة ينتقل التركيز إلى زر الإغلاق، وعند الإغلاق يعود التركيز إلى البطاقة السابقة.
- اختيار المفضلة يمسح فلتر التصنيف حتى تظهر كل الألعاب المفضلة بدلاً من تقييدها بالتصنيف السابق.


### مكتبة ألعاب محلية
- زر إضافة لعبة يتيح إدخال الاسم، النوع، وصف مختصر، Emoji والتصنيف.
- حفظ الألعاب المضافة محلياً في `localStorage` تحت `mchaweCustomGames` دون خدمات سحابية.
- منع تكرار أسماء الألعاب، وإتاحة حذف اللعبة الخاصة من نافذة التفاصيل مع إزالتها من المفضلة أيضاً.
- الألعاب المضافة هي عناصر مكتبة فقط؛ لا يعني ذلك أن تشغيلها أو بثها متاح.
